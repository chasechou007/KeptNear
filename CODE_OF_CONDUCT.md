# Code Of Conduct

This project should remain a respectful, technically focused space.

## Expected Behavior

- Be direct, constructive, and specific.
- Critique code, designs, and decisions rather than people.
- Assume security and privacy concerns are serious until assessed.
- Avoid sharing private user data, credentials, or real vault material.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private information without permission.
- Posting exploit details for unresolved vulnerabilities in public issues.
- Submitting real password-manager exports, real vaults, or credentials as test
  data.

## Enforcement

Maintainer: Chase Chou <chasechou007@gmail.com>

Reports may be sent privately by email. Maintainer actions may include
moderation, issue locking, pull request closure, or blocking repeat abuse.
